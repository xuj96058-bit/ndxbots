# 情緒控倉

水平是五項等權後的 5 日均，刻度 0 到 1。五區切在 20/40/60/80。只有極度貪婪（>= 80）把毛曝光天花板收到 0.60。擁擠度仍是原來的算法，和水平的 5 日均值同時 >= 0.80 時同樣收到 0.60。

變化是另一套四分項的 252 日 Z-score，不拿水平做差分。前一日 Z 上穿 +1.5，變化倉位減 0.20；下穿 -1.5，加 0.20。地板 0.60，起始 1.00。實際毛曝光取天花板和變化倉位的較小值，只乘已選好的權重。

外部序列是 VIX、HYG、LQD、TLT。`python -m ndxbots.regime` 會先看面板裡有沒有 `US.HYG` / `US.LQD` / `US.TLT`，沒有就向 Yahoo 日線讀，寫到 `data/meta/sentiment_external.csv`，不進 git。

研究跑法是把這個毛曝光乘在 QQQ 上，不是 4 檔觀察池。2018-01-02 至 2026-09-18，控倉年化 16.5%，滿倉 QQQ 年化 20.1%；最大回撤 -28.7% 對 -35.1%。樣本裡收益沒有打贏滿倉，回撤較小。
